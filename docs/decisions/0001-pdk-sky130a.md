# ADR-0001：PDK 用 sky130A，不用 SKY90-FD

- 狀態：已採用（2026-10-02，使用者確認）
- 背景：原需求是 SkyWater 90nm。查證 `google/sky90fd-pdk` 已封存且停在實驗性預覽，標準元件庫 repo 沒有任何 cell，OpenRAM／LibreLane／OpenROAD 都不支援。
- 決策：改用 sky130A + `sky130_fd_sc_hd`。PDK 相依集中在 flow 設定與 `ip/sram/`，日後取得 sky90 NDA PDK 可替換。
- 出處：project-plan.md §1.2、§1.3。
